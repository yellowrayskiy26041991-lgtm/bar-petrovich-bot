# Бот "Барный Петрович"

Публикует в канал 3 новости про пиво в день, в случайное время с 8:00 до 23:00.

## Шаг 1. Получить токен бота
1. Напишите в Telegram боту **@BotFather**.
2. Команда `/newbot`, задайте имя и username.
3. Скопируйте выданный токен.

## Шаг 2. Добавить бота в канал
1. Откройте настройки канала "Барный Петрович" → Администраторы.
2. Добавьте вашего бота как администратора (достаточно прав на публикацию сообщений).

## Шаг 3. Настроить и запустить
Задайте переменные окружения (или впишите значения прямо в файл `bar_petrovich_bot.py`):

```bash
export BOT_TOKEN="токен_от_BotFather"
export CHANNEL="@barniy_petrovich"   # или числовой ID канала вида -1001234567890
```

Установите зависимости и запустите:

```bash
pip install -r requirements.txt
python bar_petrovich_bot.py
```

## Шаг 4. Чтобы бот работал постоянно ("запустил и работает")
Скрипт — обычный бесконечный процесс, его нужно где-то держать запущенным 24/7. Варианты:

- **Свой сервер/VPS**: запустить через `systemd` или `screen`/`tmux`, чтобы не завершался при закрытии терминала.
- **Облачный хостинг для таких скриптов**: Railway, Render, PythonAnywhere — залить туда эти файлы, задать переменные окружения BOT_TOKEN и CHANNEL, запустить `python bar_petrovich_bot.py` как worker-процесс.

## Настройки внутри скрипта
- `QUERIES` — список тем поиска новостей, можно расширить своими формулировками.
- `POSTS_PER_DAY` — сколько постов в день (сейчас 3).
- `DAY_START_HOUR` / `DAY_END_HOUR` — окно, в которое можно постить (сейчас 8:00–23:00).
- Файл `posted.json` создаётся автоматически рядом со скриптом и хранит уже опубликованные ссылки, чтобы не было повторов.
